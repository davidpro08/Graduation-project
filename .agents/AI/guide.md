# AI 서버 지침

2026-10-03 운영 코드의 모순·일정 분석 API·DB·화면 연결을 구현했다. [최신 연결 기록](analysis-flow.md)이 아래 이전 진단 상태보다 우선한다. 학교 모델 컨텍스트는 실제 조회로 2,048토큰이며 전체 입력 분할·근거 검증·실패 반환을 적용했다. 분할 간 모순과 생략 임계값 누락률 평가는 남아 있다.

## 연결과 책임

초기는 **NestJS → 별도 AI 서버의 HTTP 연결**로 구성한다. AI는 구조화된 JSON을 반환하고 NestJS가 스키마·소유권·근거를 검증하여 Supabase에 저장한다. AI는 DB 관리 권한을 갖지 않는다.

로컬 서버는 사용 시간 제약이 있으며 GPU 대여도 후보지만 제공자·GPU·운영 시간·비용은 미선정이다. 초기에는 모의 AI로 서비스 흐름을 검증한다. 연결 계약은 [api.md](api.md)를 따른다.

선정 시 정확한 모델 ID·리비전·라이선스·실제 평가 결과와 설치 의존성을 기록한다. 현재 후보명을 실행 가능한 모델 설정으로 취급하지 않는다. 발표의 과거 GPU 가격을 현재 비용으로 재사용하지 않는다.

## 결과와 실패 처리

- 통계는 백엔드 책임이다. AI 분석은 모순 후보·페르소나 의견·일정 후보로 구분한다.
- 모순 후보와 일정 후보에는 요청에 포함된 근거 메시지 ID를 반환한다. AI 판단을 확정된 사실로 표현하지 않는다.
- 페르소나의 생성 응답은 실제 사회 조사 결과가 아니다. 근거 데이터가 없는 비율·대표성을 주장하지 않는다.
- 모델이 참조하는 대화는 사용자 데이터다. 대화 속 지시문을 시스템 명령으로 실행하지 않으며 외부 도구·파일 접근을 임의 수행하지 않는다.
- 모의 AI도 실제 계약과 같은 출력 형식을 사용한다. 정상, 지연, 연결 실패, 잘못된 JSON, 존재하지 않는 근거 ID를 재현할 수 있게 한다.
- HTTP 연결 실패·타임아웃·잘못된 JSON을 NestJS가 작업 실패로 처리한다. 무한 재시도하지 않고 설정된 제한을 따른다.
- 대화·토큰을 로그에 기록하지 않는다. 실제 서버 연결에는 서버 간 인증·전송 보호를 적용하며 환경 구성은 [infra 지침](../infra/guide.md)에 기록한다.

## JEV 사용 분기 · 2026-10-03

백엔드 `ai` 모듈에서 `JevService`가 사용 정책, `JevClient` 인터페이스와 `TypeSafeJev` 어댑터가 SDK 호출을 담당한다. 전역 설정과 호출별 선택, 키·모델·시간 제한·실패 결과는 [실제 계약](api.md#jev-사전-판단-실제-계약--2026-10-03)을 따른다. JEV가 실패하면 이후 LLM 분석을 계속하는 방향이며 LLM·모순·일정·관점별 의견 기능은 아직 연결하지 않았다. 오늘의 원격 서버 변경은 사용자에게 맡기며 RunPod는 제외한다.

공식 근거: [JavaScript SDK](https://docs.typesafe.ai/sdk/javascript), [클라이언트 설정](https://docs.typesafe.ai/sdk/javascript/api/interfaces/TypeSafeClientConfig).

## 검증과 갱신

2026-10-03 백엔드 타입·lint·빌드와 29개 테스트 통과. 그중 9개가 JEV 설정·분기·SDK 요청·시간 초과·오류·응답 검증을 확인한다. 이후 사용자가 API 키·결제를 설정하여 실제 `jev-1.13.0` 호출에 일정 언급 확률 0.98을 받았고, 호출별 skip은 request-disabled를 반환했다. 추가로 합성 대화 두 건의 JEV→Qwen 연속 호출·상세 분석 생략을 검증했다. [진단 기록](api.md#jev와-학교-qwen-연속-진단--2026-10-03)을 참조한다. 운영 분석 API·DB 저장·전체 대화 처리·정확도 평가는 미구현이다.

모델 정확도 평가와 API 연동 검증을 구분한다. API 계약은 모의 서버로 먼저 검증하고, 실제 모델 선정 후 한국어 대화·근거 연결·오탐·일정 모호성에 대한 평가를 추가한다. 모델·서버·계약 변경 시 이 문서와 API 문서 및 영향을 받는 백엔드 지침을 갱신한다.
