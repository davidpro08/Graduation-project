# 로그인 브랜드 리소스

제공자 공식 리소스를 그대로 보관한다. 버튼 PNG·SVG와 로고는 임의로 다시 그리거나 색상·비율을 변경하지 않았다.

| 파일 | 출처·사용 |
| --- | --- |
| google-signin.png | [공식 로그인 ZIP](https://developers.google.com/static/identity/images/signin-assets.zip)의 Android + Web / PNG @2x / Light / Show text=Yes / Shape=Square. 공식 영문 버튼 문구를 유지하고 접근성 이름은 한국어로 제공 |
| kakao-login.svg | [공식 리소스 페이지](https://developers.kakao.com/tool/resource/login)의 [한국어 완성형 버튼](https://developers.kakao.com/tool/images/resource/preview/login-complete-ko.svg) |
| github-invertocat-white.svg | [공식 로고 ZIP](https://brand.github.com/GitHub_Logos.zip)의 GitHub Logos / SVG / GitHub_Invertocat_White.svg. GitHub 로그인 버튼에서 서비스 통합을 표시 |

기준: [Google 브랜드 가이드](https://developers.google.com/identity/branding-guidelines), [카카오 로그인 디자인 가이드](https://developers.kakao.com/docs/ko/kakaologin/design-guide), [GitHub 브랜드 가이드](https://brand.github.com/foundations/logo). 이미지 버튼은 종횡비를 유지하고 세 제공자에 같은 버튼 영역을 제공한다. GitHub는 공식 로고와 별도 한국어 로그인 레이블을 조합한다.
